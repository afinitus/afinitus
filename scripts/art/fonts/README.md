Static weight instances of two SIL Open Font License 1.1 fonts, used to outline all text in the README art
(GitHub serves README images with a CSP that blocks fonts, so text has to ship as paths):

- `grotesk-{400,700}.ttf`: Space Grotesk (https://github.com/floriankarsten/space-grotesk), license in `OFL-SpaceGrotesk.txt`
- `mono-{400,500,700}.ttf`: JetBrains Mono (https://github.com/JetBrains/JetBrainsMono), license in `OFL-JetBrainsMono.txt`

`../../glyphs.json` holds outlines extracted from them by `../build_glyphs.py` for the stats card; it is under the same licenses.
